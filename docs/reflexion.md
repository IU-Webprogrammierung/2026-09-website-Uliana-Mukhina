# Reflexion zur zweiten Phase

Textvorschlag für das Textfeld in PebblePad; vor der Abgabe an die eigenen Erfahrungen und tatsächlich erhaltenes Feedback anpassen:

> In der zweiten Phase habe ich das Konzept meiner Reisewebsite konkretisiert und das responsive Layout mit eigenem CSS umgesetzt. Die ursprünglichen Handskizzen bleiben die Grundlage. Ein cremefarbener Hintergrund, dunkle Schrift und zurückhaltende Farbakzente verbinden die verschiedenen Reiseberichte gestalterisch.
>
> Die Anordnung ist nun für drei Breitenbereiche festgelegt: Auf dem Handy stehen die Inhalte untereinander. Ab 768 Pixeln stehen im Vorstellungsbereich Text und Foto nebeneinander; ab 1024 Pixeln nutzen auch die weiteren Bereiche zwei Spalten. So bleiben Texte und Bilder auf kleinen und großen Bildschirmen übersichtlich. Grid ordnet die Inhaltsbereiche und Fotos an, Flexbox die Navigation und Bedienelemente.
>
> Die Navigation wird auf kleineren Geräten über einen Menübutton geöffnet. Die drei Slideshows lassen sich unabhängig und ohne automatischen Bildwechsel bedienen. Da Nang behält das statische Bilderraster; Vorstellung und Kontakt zeigen jeweils ein Foto. Sichtbare Tastaturfokusse, Alternativtexte und eindeutige Beschriftungen unterstützen die Bedienbarkeit. Ohne JavaScript bleiben alle Fotos und Navigationslinks zugänglich.
